# 柯孟含 · 作品集（极简重构版）

成品只有一个文件：`index.html`。64 张素材全部以 base64 内嵌，发给别人直接打开也能看，不依赖外部图片。

## 这一版怎么极简

- **只留三段**：01 项目、02 证书、03 联系。没有单独的方法区，把「看 / 拆 / 接 / 交」收进四个项目的编号里。
- **证书不再做墙**：43 张按 6 类排成可读的档案索引，左侧小图是完整原图缩放，点开看全张；没有筛选器、没有轮播、没有瀑布流。
- **不裁切**：项目截图按原始比例完整显示；证书用 `object-fit: contain`，只看完整原图。
- **不做多余排版**：没有书架、没有 3D 翻转、没有卡片阴影、没有滚动进度条、没有跑马灯、没有装饰英文。
- **人物只留一枚小像**：左 / 右 / 低头三向，逐帧混合，跟着光标转，但不抢内容。
- **小字只留必要标签**：每个项目一句说明、四项指标、一行流程，不写重复解释。

## 页面结构

- **首屏**：由意成形；04 个项目 / 03 个端 / 1900+ 服务学生 / 43 张证书。
- **01 项目**：第二文化（看）、校园三维自助打印（拆）、青铜创市（接）、奋马职前（交）。每个项目一张小封面、四项指标、一句说明、一行流程、全部界面截图。
- **02 证书**：学科竞赛 15、专利软著 3、表彰荣誉 10、文艺体育 7、实践服务 2、技能证书 6。点任意一行看原图。
- **03 联系**：一句话 + GitHub。
