# 柯孟含 · AI FDE 作品集（极简版）

成品只有一个文件：`index.html`。60 张素材全部以 base64 内嵌，发给别人直接打开也能看，不依赖外部图片。

## 页面结构

- **01 作品**：第二文化 / 校园三维自助打印 / 青铜创市 / 奋马职前。每个项目一句说明、一行指标、全部界面截图。
- **02 方法**：看 / 拆 / 接 / 交。只讲做法，不再重复四个案例。
- **03 结果**：04 个项目、03 个端、43 张证书、1900+ 学生；3 项专利与软著单独成行；43 张证书可按 6 类筛选，点击放大。
- **关于**：一句话 + GitHub。

## 极简规则

- 不裁切：项目截图按原始比例完整显示；证书用 `object-fit: contain`，只看完整原图。
- 不做多余排版：没有书架、没有轮播、没有 3D 翻转、没有卡片阴影、没有滚动进度条、没有跑马灯。
- 小字只保留必要标签；每个项目只留一句说明。
- 保留人物跟随：左 / 右 / 低头三向，逐帧混合，不闪。
- 证书查看支持：点击、左右键、滚轮、Esc。
